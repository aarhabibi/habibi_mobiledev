# Flutter — @habibi.mobiledev

Contoh kode Flutter.

## Cara mencoba

Untuk kode Flutter:
1. Buat proyek: `flutter create coba_flutter`
2. Salin file `main.dart` dari hari yang ingin dicoba.
3. Ganti isi `coba_flutter/lib/main.dart` dengan kode tersebut.
4. Jalankan dari folder proyek dengan `flutter run`.
